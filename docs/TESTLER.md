# Doğrulama ve test durumu

Üretim sırasında WIM bütünlüğü, kritik dosya/tema hashleri, ISO envanteri ve BIOS/UEFI açılış kataloğu denetlendi. Bunlar kurulum veya uygulama uyumluluğu testi değildir. ULUTÜRK WIM'i ERTÜRK ile bayt bayt aynı olduğu için onun WIM doğrulamasını devralır; dock ekleri ayrıca dosya hashleriyle denetlendi.

Bu kesin ISO sürümü için kullanıcı kurulum testi henüz kayıtlı değildir.



Bu GitHub yayını için büyük ISO yeniden hesaplanmadı; üretim raporundaki boyut/hashler yerel dosya boyutu ve hash yan dosyalarıyla karşılaştırıldı. Fiziksel donanım, uzun dönem kararlılık, düşük RAM hedefi ve bütün uygulamalar için test sonucu yoktur.
