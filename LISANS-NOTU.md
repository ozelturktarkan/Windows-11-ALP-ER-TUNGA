# Lisans kapsamı

Windows, NTLite ve MyDockFinder kendi sahiplerinin lisanslarına tabidir. Bu depo Windows lisansı veya aktivasyon hakkı sağlamaz. Windows ISO ve üçüncü taraf dock uygulama ikilileri GitHub paketine dahil değildir. Görsellerin, imlecin ve çevirilerin paylaşılması Windows bileşenlerini kamu malı yapmaz; tüm içerik için toplu Public Domain/CC0 iddiası yoktur.
